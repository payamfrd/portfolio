# JavaScript چیست؟ راهنمای کامل یادگیری جاوااسکریپت

JavaScript یک زبان برنامه‌نویسی عمومی است که بیشتر به‌خاطر ایجاد رفتار و تعامل در وب‌سایت‌ها شناخته می‌شود.

جاوااسکریپت یکی از فناوری‌های اصلی وب مدرن است:

- **HTML** ساختار و محتوای صفحه را مشخص می‌کند.
- **CSS** ظاهر و نحوه نمایش صفحه را کنترل می‌کند.
- **JavaScript** رفتار، منطق و تعاملات صفحه را مدیریت می‌کند.

JavaScript فقط به مرورگر محدود نیست و می‌تواند در محیط‌های دیگری مانند Runtimeهای سمت سرور از جمله Node.js نیز اجرا شود.

در این مقاله با JavaScript، نقش آن در توسعه وب، ویژگی‌های اصلی، DOM و نحوه استفاده از JavaScript خارج از مرورگر آشنا می‌شویم.

## JavaScript چیست؟

JavaScript یک زبان برنامه‌نویسی سطح بالا، دارای Typing پویا و چندپارادایمی است.

این زبان در ابتدا برای ایجاد تعامل در صفحات وب طراحی شد، اما امروزه از سبک‌های مختلف برنامه‌نویسی مانند برنامه‌نویسی دستوری، تابعی و شیءگرا پشتیبانی می‌کند.

استاندارد زبان JavaScript با نام **ECMAScript** شناخته می‌شود. مشخصات ECMAScript هسته اصلی زبان را تعریف می‌کند، در حالی که محیط‌هایی مانند مرورگر و Node.js APIهای بیشتری برای ارتباط برنامه با محیط اطراف در اختیار آن قرار می‌دهند.

در مرورگر، JavaScript می‌تواند با Web APIهایی مانند DOM کار کند، به رویدادهای کاربر پاسخ دهد، محتوای صفحه را تغییر دهد و با سرورها ارتباط برقرار کند.

## چرا JavaScript مهم است؟

JavaScript به توسعه‌دهندگان اجازه می‌دهد وب‌سایت‌ها و برنامه‌های وب تعاملی و پویا ایجاد کنند.

برای مثال از JavaScript می‌توان برای پیاده‌سازی موارد زیر استفاده کرد:

- منوهای تعاملی
- اعتبارسنجی فرم‌ها
- تغییر محتوای صفحه
- منطق برنامه‌های سمت کاربر
- ارتباط با APIها
- داشبوردهای تعاملی
- رابط‌های کاربری پویا
- برنامه‌های تحت وب

امروزه اکوسیستم JavaScript شامل فریمورک‌ها، کتابخانه‌ها، Runtimeها، ابزارهای توسعه و ابزارهای Build متعددی است.

## تاریخچه JavaScript

JavaScript توسط **Brendan Eich در شرکت Netscape** ایجاد شد و اولین بار در سال 1995 در Netscape Navigator 2.0 ظاهر شد.

این زبان در مراحل اولیه توسعه نام‌های مختلفی داشت و در نهایت با نام JavaScript شناخته شد.

با وجود شباهت اسمی، **JavaScript و Java دو زبان برنامه‌نویسی متفاوت** با طراحی، سینتکس و مدل اجرایی متفاوت هستند.

در سال 1996 فرایند استانداردسازی JavaScript با همکاری Ecma International آغاز شد و اولین نسخه استاندارد ECMAScript با نام ECMA-262 در سال 1997 تصویب شد.

امروزه ECMAScript همچنان به‌عنوان استاندارد زبان اصلی JavaScript توسعه پیدا می‌کند.

## ویژگی‌های مهم JavaScript

### Typing پویا

JavaScript یک زبان Dynamically Typed است.

یعنی هنگام تعریف متغیر، لازم نیست نوع داده آن را مانند `string` یا `number` به‌صورت جداگانه مشخص کنیم.

برای مثال:

```javascript
let value = 25;
value = "Hello";
```

یک متغیر می‌تواند در طول اجرای برنامه به مقادیر با نوع‌های مختلف اشاره کند.

### توابع به‌عنوان مقدار

در JavaScript، Functionها First-Class Value هستند.

یعنی تابع می‌تواند:

- در یک متغیر ذخیره شود.
- به‌عنوان آرگومان به تابع دیگری ارسال شود.
- از یک تابع دیگر برگردانده شود.
- داخل Object یا Array ذخیره شود.

مثال:

```javascript
function greet(name) {
  return `Hello ${name}`;
}

const message = greet;

console.log(message("Payam"));
```

### چندپارادایمی بودن

JavaScript از چند سبک برنامه‌نویسی پشتیبانی می‌کند.

از جمله:

- برنامه‌نویسی دستوری
- برنامه‌نویسی تابعی
- برنامه‌نویسی شیءگرا
- برنامه‌نویسی مبتنی بر رویداد

این انعطاف‌پذیری یکی از دلایل کاربرد گسترده JavaScript در پروژه‌های مختلف است.

### مدل شیءگرایی مبتنی بر Prototype

JavaScript از یک مدل شیءگرایی مبتنی بر Prototype استفاده می‌کند.

JavaScript مدرن همچنین دارای سینتکس `class` است، اما Classها روی مدل Prototype-based زبان ساخته شده‌اند.

درک این موضوع برای یادگیری مفاهیم پیشرفته‌ای مانند Inheritance و Prototype Chain اهمیت دارد.

### اکوسیستم گسترده

JavaScript دارای اکوسیستم بسیار بزرگی از کتابخانه‌ها، فریمورک‌ها، Runtimeها، Package Managerها و ابزارهای توسعه است.

برخی فناوری‌های معروف این اکوسیستم عبارت‌اند از:

- React
- Next.js
- Node.js
- Vue.js
- Angular
- Express

این فناوری‌ها همگی خود زبان JavaScript نیستند و هرکدام کاربرد و نقش متفاوتی دارند.

## یک مثال ساده از JavaScript

در مثال زیر یک تابع ساده تعریف شده است:

```javascript
function greet(name) {
  return `Hello ${name}`;
}

console.log(greet("Payam"));
```

خروجی:

```text
Hello Payam
```

تابع مقدار `name` را دریافت می‌کند، با استفاده از Template Literal یک رشته ایجاد می‌کند و نتیجه را برمی‌گرداند.

## متغیرها در JavaScript

برای نگهداری مقادیر از Variable استفاده می‌شود.

در JavaScript مدرن معمولاً از موارد زیر استفاده می‌کنیم:

- `let`
- `const`

مثال:

```javascript
let name = "Payam";
const age = 25;
```

زمانی که Binding متغیر نباید دوباره مقداردهی شود، معمولاً از `const` استفاده می‌کنیم و زمانی که نیاز به Reassignment داریم، از `let` استفاده می‌کنیم.

JavaScript دارای `var` نیز هست، اما در کدهای مدرن معمولاً `let` و `const` ترجیح داده می‌شوند.

## انواع داده‌ها در JavaScript

JavaScript دارای انواع داده مختلفی است.

برای مثال:

```javascript
let name = "Ali"; // String
let age = 25; // Number
let active = true; // Boolean
let skills = ["JavaScript", "React"]; // Array
let user = { name: "Ali" }; // Object
```

انواع مهم دیگری مانند موارد زیر نیز وجود دارند:

- `undefined`
- `null`
- `bigint`
- `symbol`

شناخت Typeها یکی از پایه‌های مهم یادگیری JavaScript است.

## توابع

Functionها به ما کمک می‌کنند بخش‌های قابل استفاده مجدد از منطق برنامه را سازمان‌دهی کنیم.

برای مثال:

```javascript
function sum(a, b) {
  return a + b;
}

console.log(sum(10, 20));
```

توابع می‌توانند در متغیرها ذخیره شوند، به توابع دیگر ارسال شوند، از توابع دیگر برگردانده شوند و به‌عنوان Callback مورد استفاده قرار بگیرند.

این مفهوم در کار با Arrayها، Eventها، Promiseها و فریمورک‌های مدرن JavaScript اهمیت زیادی دارد.

## شرط‌ها

Conditional Statementها به برنامه اجازه می‌دهند بر اساس شرایط مختلف تصمیم‌گیری کند.

```javascript
const age = 25;

if (age >= 18) {
  console.log("Adult");
} else {
  console.log("Under 18");
}
```

JavaScript ساختارهای دیگری مانند `switch`، Conditional Operator و Logical Operatorها نیز دارد.

## حلقه‌ها

Loopها زمانی استفاده می‌شوند که بخشی از کد باید چندین بار اجرا شود.

برای مثال:

```javascript
for (let i = 0; i < 5; i++) {
  console.log(i);
}
```

JavaScript همچنین از موارد زیر پشتیبانی می‌کند:

- `while`
- `do...while`
- `for...of`
- `for...in`

انتخاب نوع Loop به داده و عملیاتی که قرار است انجام شود بستگی دارد.

## DOM چیست؟

**DOM یا Document Object Model** یک API ارائه‌شده توسط مرورگر است که سند HTML را به ساختاری از Objectها تبدیل می‌کند تا JavaScript بتواند با آن تعامل داشته باشد.

به کمک DOM، JavaScript در مرورگر می‌تواند محتوای صفحه را بخواند و تغییر دهد و به تعاملات کاربر پاسخ دهد.

برای مثال:

```javascript
document.getElementById("title").textContent = "Hello";
```

اگر عنصری با شناسه `title` وجود داشته باشد، این کد محتوای متنی آن را تغییر می‌دهد.

DOM بخشی از Web Platform است و باید آن را از هسته اصلی زبان ECMAScript جدا دانست.

## JavaScript و توسعه فرانت‌اند

JavaScript یکی از فناوری‌های اصلی توسعه Frontend است.

توسعه‌دهندگان از JavaScript برای ساخت رابط‌های تعاملی، ارتباط با APIها، مدیریت State و پیاده‌سازی منطق سمت کاربر استفاده می‌کنند.

فناوری‌های معروف JavaScript عبارت‌اند از:

- [React](/fa/blog/what-is-react-js)
- [Next.js](/fa/blog/what-is-next-js)
- Vue.js
- Angular

React و Vue در اکوسیستم JavaScript قرار دارند و Next.js یک Framework مبتنی بر React است. این فناوری‌ها جایگزین یادگیری خود زبان JavaScript نیستند.

اگر هنوز با مفاهیم پایه برنامه‌نویسی آشنا نیستید، مطالعه مقاله [الگوریتم چیست؟](/fa/blog/what-is-algorithm) می‌تواند به درک بهتر حل مسئله و تفکر منطقی کمک کند.

## JavaScript و Node.js

JavaScript در ابتدا بیشتر به‌عنوان زبانی برای اجرای کد در مرورگر شناخته می‌شد، اما امروزه در محیط‌های مختلفی اجرا می‌شود.

**Node.js** یک JavaScript Runtime است که امکان اجرای JavaScript خارج از مرورگر، از جمله روی سرور، را فراهم می‌کند.

با Node.js می‌توان:

- API ساخت
- سرویس‌های Backend ایجاد کرد
- با پایگاه داده کار کرد
- سیستم‌های احراز هویت ایجاد کرد
- فایل‌ها را خواند و نوشت
- ابزارهای خط فرمان ساخت
- سرویس‌های HTTP و WebSocket ایجاد کرد

Node.js قابلیت‌ها و APIهای Runtime را در اختیار JavaScript قرار می‌دهد و این قابلیت‌ها بخشی از هسته استاندارد ECMAScript نیستند.

## JavaScript خارج از مرورگر

JavaScript امروزه در محیط‌های دیگری نیز استفاده می‌شود.

بسته به Runtime و اکوسیستم مورد استفاده، می‌توان از JavaScript برای موارد زیر استفاده کرد:

- برنامه‌های سمت سرور
- برنامه‌های دسکتاپ
- برنامه‌های موبایل
- اسکریپت‌ها و Automation
- برخی سیستم‌های Embedded و تخصصی

برای مثال Electron برای ساخت برنامه‌های Desktop کاربرد دارد و React Native از JavaScript یا TypeScript در کنار کامپوننت‌های Native برای توسعه اپلیکیشن موبایل استفاده می‌کند.

بنابراین JavaScript از یک زبان اسکریپت‌نویسی مرورگر به یک زبان عمومی‌تر با کاربرد در محیط‌های مختلف تبدیل شده است.

## JavaScript و برنامه‌نویسی Asynchronous

برنامه‌نویسی Asynchronous یکی از بخش‌های مهم JavaScript مدرن است.

این قابلیت به برنامه اجازه می‌دهد عملیاتی مانند درخواست شبکه را بدون متوقف کردن اجرای منطقی وابسته به آن، تا زمان آماده‌شدن نتیجه مدیریت کند.

JavaScript برای برنامه‌نویسی Asynchronous ابزارهای مختلفی دارد، از جمله:

- Callbackها
- Promiseها
- `async` / `await`

برای مثال:

```javascript
async function loadUser() {
  const response = await fetch("/api/user");
  const user = await response.json();

  console.log(user);
}
```

برای درک بهتر رفتار Asynchronous در JavaScript، مفاهیمی مانند Promise و Event Loop نیز اهمیت زیادی دارند.

## مزایای JavaScript

برخی از مزایای مهم JavaScript عبارت‌اند از:

- اجرا در مرورگرهای مدرن
- اکوسیستم گسترده
- کاربرد بسیار زیاد در توسعه وب
- پشتیبانی از چندین Paradigm برنامه‌نویسی
- قابلیت اجرا در محیط‌های Browser و Server
- جامعه توسعه‌دهندگان بزرگ
- وجود کتابخانه‌ها و Frameworkهای فراوان
- کاربرد در انواع مختلف پروژه‌ها

البته JavaScript پیچیدگی‌ها و محدودیت‌های خودش را نیز دارد. برای تبدیل‌شدن به یک توسعه‌دهنده قوی، یادگیری مفاهیم اصلی زبان بسیار مهم‌تر از یادگیری صرفاً یک Framework است.

JavaScript همچنان یکی از فناوری‌های پایه توسعه وب مدرن است و برای بسیاری از مسیرهای توسعه Frontend اهمیت اساسی دارد.

اگر می‌خواهید:

## جمع‌بندی

JavaScript یک زبان برنامه‌نویسی عمومی است که نقش بسیار مهمی در توسعه وب مدرن دارد.

هسته زبان، قابلیت‌های اصلی برنامه‌نویسی را فراهم می‌کند و محیط‌هایی مانند Browser و Node.js امکانات و APIهای بیشتری برای اجرای برنامه و ارتباط با محیط اطراف در اختیار آن قرار می‌دهند.

به همین دلیل، داشتن پایه قوی در JavaScript بسیار ارزشمندتر از یادگیری صرفاً یک Framework است.

وقتی مفاهیم اصلی JavaScript را به‌خوبی یاد بگیرید، یادگیری فناوری‌هایی مانند React و Next.js نیز بسیار ساده‌تر و مؤثرتر خواهد شد.
